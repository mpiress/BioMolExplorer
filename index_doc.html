A Flexible Information Retrieval Architecture for Exploring and Assembling Molecular Space Domains For Drug Discovery Based on Computer-Aided Drug Design Strategies

Gerenciar a vasta complexidade das relações composto-alvo tornou-se um desafio crescente no planejamento de fármacos auxiliado por computador (CADD). Repositórios de fármacos enriquecidos com metadados heterogêneos frequentemente excedem os limites das estratégias tradicionais. O BioMolExplorer foi projetado para integrar, padronizar e automatizar esses pipelines complexos, estruturando redes de relacionamento fármaco-alvo e limpando ruídos computacionais.

Bancos Integrados

Extração robusta, padronizada e unificada de estruturas tridimensionais, dados farmacológicos e bibliotecas virtuais via PDB, ChEMBL e ZINC.

Camada de Curação

Validação sistemática de complexos através de rotinas automáticas de redocking baseadas no motor AutoDock Vina e cálculo de RMSD.

Análise de Grafos

Mapeamento do espaço químico focando na Componente Conectada Máxima para identificar andaimes estruturais (scaffolds) comuns.

Vantagens Estratégicas

Recuperação Abrangente: Acesso unificado a extensos bancos de bioatividades para triagem virtual.
Filtros Customizados: Restrição total orientada ao domínio científico e restrições do projeto de pesquisa.
Minimização de Etapas Manuais: Automação completa de tarefas exaustivas de curadoria preliminar de dados.
Modelos Baseados em Assinaturas: Agrupamento molecular por afinidade estrutural ideal para Machine Learning e Redes de Polifarmacologia.

Instalação Geral de Dependências (Qualquer Linux)

BioMolExplorer opera nativamente em arquiteturas Linux. Siga o passo a passo rigoroso abaixo para provisionar as ferramentas necessárias de background:

1. Instalação do Anaconda

Obtenha o instalador para Linux do site oficial e aplique as permissões de execução:

chmod +x Anaconda3-latest-Linux-x86_64.sh
./Anaconda3-latest-Linux-x86_64.sh
2. Provisionamento do Ambiente Conda

Navegue até o diretório raiz clonado do projeto onde o arquivo environment.yml está situado:

conda env create -f environment.yml
3. Instalação Externa do UCSF Chimera

Obrigatório para rotinas silenciosas de limpeza proteica e tratamento de cofactores. Obtenha a versão estável (.bin) e execute:

chmod +x chimera.bin
./chimera.bin

Provisionamento Automatizado (Ubuntu 24.04)

Se o ambiente operacional for Ubuntu Linux, você poderá fazer o upload prévio dos binários para que o script install.sh orquestre a instalação completa.

Árvore de Diretórios Exigida para Automação:

BioMolExplorer/
├── apps/
│   ├── Anaconda-latest-Linux-x86_64.sh  <-- Renomear arquivo baixado
│   └── chimera.bin                      <-- Renomear arquivo baixado
├── environment.yml
└── install.sh
Comandos de Execução do Instalador: 
chmod +x install.sh
./install.sh

Módulo de Download e Filtro de Estruturas Proteicas (PDB)

O script 11-pdb.py realiza consultas automatizadas ao RCSB Protein Data Bank com base em parâmetros rígidos de qualidade estrutural.

workflow/InformationRetrieval/11-pdb.py
from src.core.retrieval import load_pdb, PolymerEntityType, ExperimentalMethod

load_pdb(
    target='Monoamine Oxidase B', 
    base_output_path='/datasets', 
    pdb_ec='1.4.3.1',
    PolymerEntityTypeID=[PolymerEntityType.PROTEIN],
    ExperimentalMethodID=[ExperimentalMethod.X_RAY_DIFFRACTION],
    max_resolution=2.0, 
    must_have_ligand=True
)

Detalhamento Técnico dos Parâmetros:

Parâmetro Definição Técnica e Impacto no Filtro
targetNome da pasta de saída que será gerada no diretório raiz configurado. Ex: /datasets/Monoamine Oxidase B/
pdb_ecNúmero Enzyme Commission. Mapeia estritamente classes enzimáticas pelas reações catalisadas. (Ex: '1.4.3.1')
PolymerEntityTypeIDTipo da macromacromolécula biológica alvo. Suporta PROTEIN, DNA, ou RNA.
ExperimentalMethodIDTécnica experimental aceita para resolução estrutural. Métodos válidos: X_RAY_DIFFRACTION, NMR, CRYO_EM.
max_resolutionTeto limite de Resolução em Ångströms (Å). Valores mais baixos garantem densidades eletrônicas e posições atômicas mais precisas.
must_have_ligandFiltro booleano. Se True, rejeita automaticamente apoproteínas (estruturas desprovidas de ligantes complexados).

Módulo Crawler de Bioatividades (ChEMBL)

O módulo 12-chembl.py invoca crawlers em background localizados em src/scripts/crawlers para minerar dados farmacológicos quantitativos.

workflow/InformationRetrieval/12-chembl.py
from src.scripts.crawlers import load_chembl

load_chembl(
    target_name='monoamine oxidase',
    base_output_path='/datasets'
)

Filtros Internos do Crawler Embutido

Filtro 1: Alvo Terapêutico (Target JSON) 
{
  "organism": "Homo sapiens",
  "type__in": ["SINGLE PROTEIN"],
  "relationship_type": "DIRECT"
}
Garante a seleção exclusiva de proteínas isoladas humanas associadas diretamente à pesquisa.
Filtro 2: Restrição de Ensaios Biológicos 
{
  "standard_type__in": ["Ki", "IC50"],
  "molecule_type": "small molecule",
  "max_value_ref": 1000,
  "standard_units": "nM",
  "natural_product": 0
}
Filtra afinidades em nM (teto 1000) de pequenas moléculas sintéticas, excluindo produtos naturais (natural_product: 0).
Estrutura de Busca para Compostos Similares (Matriz Expandida):

Os scripts auxiliares também expandem a busca para análogos estruturais através das regras de corte:

{ "similarity": 60, "molecule_weight": 500 }
Filtra por limite de similaridade estrutural mínima de 60% e peso molecular máximo limitado a 500 Da (Regra de Lipinski).

Integração e Importação em Lote via ZINC Database

Destinado ao download massivo de estruturas químicas tridimensionais (strings SMILES). Diferente dos demais módulos, esta etapa requer uma ação manual preparatória.

workflow/InformationRetrieval/13-zinc.py
from src.core.retrieval import load_zinc

load_zinc(
    base_output_path='/datasets/ZINC',
    filename='ZINC2D.uri',
    verbose=True
)
Diretrizes de Execução Obrigatórias (Protocolo ZINC)
  1. Acesse o portal oficial do ZINC e baixe o arquivo de mapeamento contendo os URIs desejados em formato 2D/3D.
  2. Salve este arquivo com o nome exato definido no parâmetro (ex: ZINC2D.uri).
  3. Insira o arquivo **dentro** da pasta definida na variável base_output_path antes de rodar o script no terminal.

Curação de Estruturas: Pipeline de Redocking Automático

Para certificar o alinhamento cristalográfico, o script 21-redocking.py limpa as estruturas nativas via UCSF Chimera e calcula o desvio quadrático médio (RMSD) através do AutoDock Vina.

workflow/Analysis/21-redocking.py
from src.core.analysis import perform_redocking

perform_redocking(
    base_input_path='/datasets/PDB',
    target='MonoamineOxidaseB',
    base_output_path='/resultados/redocking',
    prepare_complex=True,
    charge_type='am1'
)
Fluxo de Preparação (prepare_complex=True)

O pipeline gera em background uma pasta chamada Prepared/ e executa um script bash dinâmico no terminal do Chimera para expurgar moléculas indesejadas:

open {input_complex}.pdb
delete solvent
delete element.H
select #0:.{chain} | :FAD
select invert
delete selected
write format pdb #0 {output_complex}.complex.pdb
close session
Guia de Edição do Script Chimera

Para garantir a estabilidade do fluxo de background do software, recomenda-se alterar estritamente a linha de seleção de cofatores químicos. Mantendo todos os outros comandos estáticos.

Incluir Cofator (Ex: FAD):
select #0:.{chain} | :FAD

Ignorar / Excluir Cofatores:
select #0:.{chain}

Processamento Estatístico, Fingerprints e Análise de Redes

O módulo 22-dataAnalysis.py processa as matrizes de similaridade química e agrupa os compostos por assinatura de afinidade molecular.

workflow/Analysis/22-dataAnalysis.py
from src.core.math import generate_fingerprints, compute_similarity, analyze_graphs

# Passo 1: Geração Simultânea de Descritores de Assinatura Química
generate_fingerprints(base_input_path='/datasets/ChEMBL/DrugBank', morgan=True, maccs=True, pharmacophore=True)

# Passo 2: Cálculo de Matriz Multiparâmetro via Distância de Tanimoto
compute_similarity(
    base_input_path='/datasets/ChEMBL/DrugBank/Fingerprints',
    base_output_path='/datasets/ChEMBL/DrugBank',
    metric=similarityFunctions.TanimotoSimilarity,
    fingerprint=fingerprints.Morgan
)

# Passo 3: Modelagem Macroscópica de Grafos e Componentes Conectadas
analyze_graphs(
    base_input_path='/datasets/ChEMBL/DrugBank',
    base_output_path='/resultados/grafos',
    metric=similarityFunctions.TanimotoSimilarity,
    fingerprint=fingerprints.Morgan
)
Fase 1: Descritores

Converte dados tabulares em vetores matemáticos binários estruturados. Gera matrizes de Morgan (circulares), MACCS keys (chaves de fragmento fixas) e Pharmacophore simultaneamente.

Fase 2: Similaridade

Aplica funções lineares baseadas na métrica de Coeficiente de Tanimoto para comparar a similaridade de pares de fingerprints, salvando as referências em uma subpasta dedicada.

Fase 3: Grafos Metodológicos

Estabelece cada composto como um nó e conexões baseadas em limiares mínimos. Filtra ruídos isolando a Componente Conectada Máxima para obter os núcleos de andaimes (scaffolds) moleculares.

Como Executar Qualquer Script do Pipeline no Linux

1. Alinhe os parâmetros desejados nos blocos internos das funções do arquivo script .py.

2. Abra o terminal integrado, navegue até a pasta do arquivo e execute via linha de comando:

python nome_do_script.py
