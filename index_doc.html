Exemplos de Uso

A Flexible Information Retrieval Architecture for Exploring and Assembling Molecular Space Domains For Drug Discovery Based on Computer-Aided Drug Design Strategies

Gerenciar a vasta complexidade das relações composto-alvo tornou-se um desafio crescente no planejamento de fármacos auxiliado por computador (CADD). O BioMolExplorer foi projetado para integrar, padronizar e automatizar pipelines complexos usando bases de dados de alta relevância científica.

Bancos Integrados

Extração robusta e padronizada de estruturas tridimensionais, dados farmacológicos e bibliotecas virtuais via PDB, ChEMBL e ZINC.

Camada de Curação

Validação automatizada de complexos por meio de rotinas de redocking acopladas ao motor do AutoDock Vina e controle de RMSD.

Principais Vantagens

  • Recuperação abrangente de dados biológicos.
  • Análises focadas em alvos terapêuticos específicos.
  • Minimização de etapas manuais e exaustivas de curadoria.
  • Geração de conjuntos de dados prontos para Machine Learning.

Instalação Geral de Dependências

Siga os passos abaixo para configurar manualmente o ambiente em qualquer distribuição Linux de sua preferência:

Passo 1 — Instalação do Anaconda

Baixe o instalador oficial do site da Anaconda e execute no terminal:

chmod +x Anaconda3-latest-Linux-x86_64.sh
./Anaconda3-latest-Linux-x86_64.sh
Passo 2 — Criação do Ambiente Conda

Navegue até a pasta raiz do projeto onde o arquivo environment.yml está localizado:

conda env create -f environment.yml
Passo 3 — Instalação do UCSF Chimera

O Chimera é mandatório para a etapa de limpeza e tratamento automatizado dos complexos moleculares proteicos:

chmod +x chimera.bin
./chimera.bin

Instalação Automatizada (Ubuntu 24.04)

Se você utiliza o ecossistema Ubuntu Linux, o projeto oferece uma infraestrutura de script bash para automatizar as etapas de download e provisionamento das ferramentas básicas.

Estrutura de Diretórios Recomendada: Para que o instalador automatizado opere de maneira correta, alinhe os binários conforme a árvore abaixo:

BioMolExplorer/
├── apps/
│   ├── Anaconda-latest-Linux-x86_64.sh
│   └── chimera.bin
├── environment.yml
└── install.sh
Execução do Instalador: 
chmod +x install.sh
./install.sh

Módulo de Download e Filtro do PDB

A função load_pdb foi projetada para recuperar estruturas macromoleculares do Protein Data Bank utilizando restrições estritas de controle de qualidade.

workflow/InformationRetrieval/11-pdb.py
from src.core.retrieval import load_pdb, PolymerEntityType, ExperimentalMethod

load_pdb(
    target='Monoamine Oxidase B', 
    base_output_path='/datasets', 
    pdb_ec='1.4.3.1',
    PolymerEntityTypeID=[PolymerEntityType.PROTEIN],
    ExperimentalMethodID=[ExperimentalMethod.X_RAY_DIFFRACTION],
    max_resolution=2.0, 
    must_have_ligand=True
)

Parâmetros Explicados:

Parâmetro Definição Técnica
pdb_ecNúmero EC (Enzyme Commission) para rastrear reações catalíticas alvo. Ex: '1.4.3.1'
max_resolutionFiltro de Resolução em Ångströms (valores menores implicam maior qualidade).
must_have_ligandSe True, ignora estruturas apoproteicas (sem ligantes complexados).

Módulo de Extração de Bioatividades (ChEMBL)

O pipeline do ChEMBL consome crawlers nativos localizados em src/scripts/crawlers para raspar alvos biológicos, bioatividades (IC_{50}, K_i) e propriedades de pequenas moléculas.

workflow/InformationRetrieval/12-chembl.py
from src.scripts.crawlers import load_chembl

load_chembl(
    target_name='monoamine oxidase',
    base_output_path='/datasets'
)
Filtro de Alvo Padrão (JSON) 
{
  "organism": "Homo sapiens",
  "type__in": ["SINGLE PROTEIN"],
  "relationship_type": "DIRECT"
}
Restrição de Bioatividade 
{
  "standard_type__in": ["Ki", "IC50"],
  "molecule_type": "small molecule",
  "max_value_ref": 1000,
  "standard_units": "nM"
}

Integração com ZINC Database

O ZINC é utilizado para download em massa de estruturas químicas 3D mapeadas por strings SMILES. É obrigatório coletar previamente o arquivo de mapeamento de URIs diretamente no portal do ZINC.

workflow/InformationRetrieval/13-zinc.py
from src.core.retrieval import load_zinc

load_zinc(
    base_output_path='/datasets/ZINC',
    filename='ZINC2D.uri',
    verbose=True
)
Aviso Importante: Certifique-se de salvar o arquivo ZINC2D.uri no mesmo caminho parametrizado em base_output_path antes de submeter a execução ao terminal Linux.

Pipeline de Análise e Redocking

A etapa final de análise consiste na geração de descritores e na execução em background do motor AutoDock Vina utilizando o UCSF Chimera.

workflow/Analysis/21-redocking.py (Curação Estrutural)
from src.core.analysis import perform_redocking

perform_redocking(
    base_input_path='/datasets/PDB',
    target='MonoamineOxidaseB',
    base_output_path='/resultados/redocking',
    prepare_complex=True,
    charge_type='am1'
)
workflow/Analysis/22-dataAnalysis.py (Fingerprints & Redes)
from src.core.math import generate_fingerprints, compute_similarity, analyze_graphs

# 1. Geração de Fingerprints Multi-parâmetro
generate_fingerprints(base_input_path='/datasets/ChEMBL/DrugBank', morgan=True, maccs=True, pharmacophore=True)

# 2. Matriz de Similaridade Baseada em Distância Tanimoto
compute_similarity(base_input_path='/datasets/ChEMBL/.../Fingerprints', base_output_path='/datasets/ChEMBL/DrugBank', metric=similarityFunctions.TanimotoSimilarity)

# 3. Modelagem de Grafos e Componentes Conectados
analyze_graphs(base_input_path='/datasets/ChEMBL/DrugBank', base_output_path='/resultados/grafos', metric=similarityFunctions.TanimotoSimilarity)
