Platform Overview

Molecular Exploration, Organized Around Your Research

Computer-aided drug design brings together protein structures, compound libraries and bioactivity records. Inconsistent metadata, duplicate compounds and incomplete experimental information make that integration difficult. BioMolExplorer organizes retrieval, filtering and analysis in one project.

Retrieve and standardize datasets from PDB, ChEMBL, PubChem and ZINC, or import compatible files from your own study. Choose a short screening workflow or combine molecular similarity, network analysis and receptor-based docking as your research requires.

The Flet workspace lets researchers create private projects, invite collaborators and connect scientific stages in the order required by their study. Separate ChEMBL and PubChem blocks retrieve compounds; PubChem also accepts a SMILES, CID or name directly and supports similarity searches. ADMET screening, graph selection, preparation, redocking and docking can be configured independently, with results and logs kept for each run. Scientific interpretations still require validation with study data.

Flet Workspace

Your project. Your pipeline. Your collaborators.

Use collapsible navigation and execution groups in the sidebar, with contextual help for each action. Drag stages onto a spacious, zoomable canvas, organize their layout, connect their ports, and double-click each block to configure it. Guided forms handle filters and engine settings; advanced users can edit JSON and scientific templates. Start with a ready-made pipeline or bring your own data wherever the backend format allows.

Projects that travel with you

Choose a folder for each project. Export and import its configuration, inputs, results and versions to continue on another computer while reusing compatible completed experiments.

Collaborate with a shared history

Invite editors or viewers from the project's Share button. Autosaved edits appear for collaborators, while an attributed change history lets owners restore configuration, files and results to an earlier state.

Select the inputs your study needs

Combine selected output files and validated uploads in each block. Saved file selections are respected without repeating the selection dialog. Explore paginated compound tables directly in your results, or filter interactive ADMET EGG plots by BBB and HIA classification. Click a point to open its molecular 2D structure and download the selected dataset or chart.

Compound retrieval → ADMET
Fingerprints → Similarity → Graph selection → ADMET
Your prepared receptors + compounds → Vina → DOCK6 → Consensus

Prepared receptors must include the metadata and files expected by the docking protocol. See the input format guide.

Keep large experiments moving

Redocking and docking use a project-scoped indexed cache with verified per-item checkpoints. Adding compounds or PDB pairs runs only missing calculations; compatible preparations, Vina poses and DOCK6 sites, grids, minimizations and footprints are reused. Completed items survive interrupted batches. Input, scientific parameter and tool changes invalidate affected calculations, while the existing reuse choice controls recovery. Vina maps remain shared within compatible batches. Individual failures are reported without discarding completed candidates.

Completed runs bring stage summaries, tables, visual results and logs together. Remove obsolete stage results with confirmation and restore files through project history.

BioMolExplorer System Architecture

The scientific modules remain organized into retrieval and analysis workflows. Above them, the Flet workspace manages accounts, project permissions, files and pipeline dependencies. Each scientific stage runs in a separate Python process, with its own configuration snapshot, outputs and logs. The layers above reflect the application services; the architecture guide documents the current application services and their limits.

Getting Started

Run the workspace in your scientific environment

Download the GitHub project using Git or Code → Download ZIP, then open a terminal in the source code folder. The Python package requires Python 3.12 or newer.

Standard preparation: configure AmberTools. DOCK6 is required for its docking protocols.

Python/Gemmi selects structures; ff14SB/GAFF and AmberTools prepare and minimize receptors and ligands. Vina uses Meeko and DOCK6 receives assigned MOL2 charges. Chimera 1.17 is optional, used only for explicitly selected legacy or special-system protocols. Scientific changes and validation limits.

Installation and executable checks (English) · Instalação e verificação (Português)

Install and start Flet

git clone https://github.com/mpiress/BioMolExplorer.git
cd BioMolExplorer
conda env create -f requirements.yml
conda activate BioMolExplorer
python -m pip install -e '.[ui]'
biomolexplorer-ui --web --dock6-path /path/to/dock6-6.11

Open http://127.0.0.1:8550 and create your account. If the environment already exists, activate it and install the interface.

Choose your execution environment

biomolexplorer-ui --web --no-browser \
  --data-dir ./workspace-data \
  --worker-python /path/to/python \
  --dock6-path /path/to/dock6-6.11

Create the isolated requirements-ambertools.yml environment and configure its root in preparation settings or BIOMOL_AMBERTOOLS_PATH. Standard preparation needs antechamber, parmchk2 and tleap; minimization also needs sander. Do not inject that environment's libraries into the main Python process. Vina and DOCK6 are required by their respective protocols; pass the complete DOCK6 root, containing bin/ and parameters/, to --dock6-path. Molecular surfaces use native Python SES, without standalone DMS. Chimera is only needed for explicit legacy execution.

Use the workspace guide for accounts and pipelines, or the backend guide for CLI usage and parameters. The current executor uses a local Linux backend, SQLite and a bounded queue; see deployment and scientific limitations.

Graph-Centric Molecular Similarity Intelligence

Connect one or more similarity stages, or upload validated external similarity CSVs. Each source produces a separate graph analysis, with isolated compounds preserved and the largest connected component (MCC) highlighted.

Explore full networks and their MCC with degree color scales, pan and zoom, and circular layouts. Hover to identify compounds and click to inspect molecular structures. Molecular inspection

Explore the pose in its receptor, relation by relation

Open Vina or DOCK6 results in the local WebGL viewer. Compare the best pose with its docking receptor and an available reference in their original coordinates. Redocking adds crystallographic ligand and complex layers; consensus offers separate 3D views for each engine.

Choose how to inspect each molecule

  • Set receptor and ligand styles independently: ribbons, sticks, spheres or lines as appropriate.
  • Show or hide ligand hydrogens retained in the file. Missing hydrogen atoms are not generated.
  • Toggle pose, receptor and reference layers; filter receptor chains and inspect atom details.
  • Show or hide interacting residue names independently of the dashed traces. Rotate, pan and zoom, then export the current scene as PNG.

Follow the dashed interaction traces

Hover over a trace for its type, residue, chain and distance. Matching legend colors and type filters help identify each relation; coincident traces are separated for inspection.

  • Green · Hydrogen bond
  • Pink · Parallel π–π
  • Coral · T-shaped π–π
  • Lilac · Hydrophobic contact
  • Lime green · Geometric van der Waals contact

Classification requires valid chemistry and residue identities; hydrogen bonds require explicit H. When classification is unavailable, heavy-atom distance contacts remain accessible. These 3D relations describe geometry. DOCK6 Footprint separately compares reference/final-pose energies per residue; neither display establishes experimental binding.
